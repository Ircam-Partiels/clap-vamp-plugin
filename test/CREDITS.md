# Test files credits

The audio files of this folder are only used to test the plugins: they are not distributed with the plugin bundle nor the installers.

## cvp.wav

The cvp.wav file (10 seconds, mono, 44.1 kHz, 24-bit) is a mix of excerpts of the following recordings. The excerpts have been cut, resampled to 44.1 kHz, converted to mono and mixed together.

### Dawn chorus

- **Title:** R4_00319-3_FR_DawnChorus.wav
- **Author:** kevp888 (Kevin Luce), [www.freesound.org](https://freesound.org/people/kevp888/)
- **Source:** https://freesound.org/s/633988/
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- **Modifications:** excerpt of the original recording (stereo, 48 kHz, 4:50), resampled to 44.1 kHz, converted to mono and mixed with other recordings.
