# Clap Vamp Plugin

<p align="center">
    <a href="https://github.com/Ircam-Partiels/clap-vamp-plugin/actions/workflows/ci.yml"><img src="https://github.com/Ircam-Partiels/clap-vamp-plugin/actions/workflows/ci.yml/badge.svg" alt="Workflows"></a>
  </p>

The Clap plugins are implementations of the [CLAP](https://github.com/LAION-AI/CLAP) and [CLAP2](https://projects.laion.ai/clap2/) contrastive language-audio models developed by [LAION](https://laion.ai/) as [Vamp plugins](https://www.vamp-plugins.org/). The plugin library contains three plugins:
- **CLAP Prompt** analyses the audio stream with text prompts provided as precomputed markers (one marker per prompt, for example generated by the tools or the annotations of the host) and generates the similarity scores of the prompts as well as tags carrying the most similar prompt. It allows zero-shot audio tagging: the sounds are described by any text prompt (in English), without training. The prompts can be organized hierarchically (for example, *Animal/Bird/Owl*).
- **CLAP Example** compares the audio stream with annotated regions of the same audio stream to tag it with the classes of the examples (few-shot tagging) and to find the parts that sound like the examples (query by example).
- **CLAP Novelty** detects the changes in the audio stream (novelty curve and boundaries), without prompt nor example.

The CLAP2 Small and CLAP2 XXS models, as well as the CLAP General and CLAP Music and Speech models (in their Q8_0 and Q4_K_M variants), are embedded in the plugin (so you don't have to download anything to start experimenting), but it is possible to download and use other models that may be more appropriate to your needs.

The Clap Vamp Plugin has been designed for use in the free audio analysis application [Partiels](https://forum.ircam.fr/projects/detail/partiels/).

## Installation

Download the Clap Vamp plugin installation package for your operating system from the [Releases](https://github.com/Ircam-Partiels/clap-vamp-plugin/releases) section and run the installer. 

## Use 

Launch the Partiels application. In a new or existing document, create a new analysis track with one of the Clap plugins. The text prompts of the CLAP Prompt plugin and the examples of the CLAP Example plugin must be provided as the precomputed markers of the plugin input (one marker per prompt or per example), for example with the tools or the annotations of the host. Modify the model or the analysis parameters via the property window. Please refer to the manual available in the [Releases](https://github.com/Ircam-Partiels/clap-vamp-plugin/releases) section for further information.

## Compilation

The compilation system is based on [CMake](https://cmake.org/), for example:
```
cmake . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest -C Release -VV --test-dir build
```
